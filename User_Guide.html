Ecosystem User Manual

Welcome to the Kumaran E-Services unified guide. This document provides clear, step-by-step instructions for managing both the Admin Control Center and the Branch Billing Terminals.

🛡️

Section I: Admin Console (Electron)

The Global View

Upon launching the Admin App, you are greeted with the Global Dashboard. Here you can see the aggregated revenue from all branches, monitor high-level stock alerts, and track investor growth.

01

Universal Product Creation

Go to Products > Add New. Enter the base details (Name, SKU, Brand). This catalog serves as the "Master List" for the entire organization.

Pro Tip: Use high-quality tags to make searching easier for your branch staff.
02

Branch Allocation

After creating a product, go to Branch Management. Select a branch and click Assign Product. Specify the initial quantity to be shipped to that location.

Section II: Billing Terminal (Vite/Web)

01

Selling Products vs Services

Product Mode: Best for physical stock like Mobiles or Cables. Search by name/sku, add to cart, and checkout. Stock is automatically decremented.

Service Mode: Ideal for Xerox/Printing. Set the volume (number of pages), select the rate, and bill instantly. No physical stock required.

Quick Action: Use the "Switch Mode" toggle at the top of the billing screen for instant transition.
02

Managing Local Inventory

Access the Products Catalog to see only the items assigned to YOUR branch. Items highlighted in RED indicate low stock.

Notify your Admin immediately if items fall below the Low Stock Threshold.

03

Daily Expense Entry

Every shop expense must be recorded under the Expenses module. Select Category (Tea, Electricity, Travel), enter Amount, and add a brief description.

This ensures your "End of Day" cash reconciles perfectly with your sales.

04

Finalizing the Sale & Printing

Upon clicking Checkout, a summary appears. Collect payment, select the Invoice Template (Professional is recommended for large orders), and click Print.

Network Hint: If internet is slow, the app uses cached data. Don't worry, the billing function will still work!
